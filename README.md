# PLAYFINDER 🎮

An installable, no-account Roblox game discovery app (Progressive Web App).

**Live app:** https://tthallow.github.io/PLAYFINDER/

## Install the app
- **Windows / macOS (Chrome or Edge):** open the live app and choose the install icon in the address bar, or use the **Install app** button.
- **Android:** open the site in Chrome, open the browser menu, and choose **Install app** or **Add to Home screen**.
- **iPhone / iPad:** open the site in Safari, tap **Share**, then **Add to Home Screen**.

## Download the source project
Use the **Download** button inside PLAYFINDER to download `PLAYFINDER-app.zip`. Extract the ZIP to get the HTML, manifest, service worker, and icon. To test PWA installation locally, serve the folder on localhost; opening the file directly does not enable service workers.

This is a Progressive Web App, not a native Windows .exe or Android .apk.

## Features
- Curated starter catalog with editorial scores and explanations
- Search, genre, play-style, difficulty and sorting filters
- Favorites saved in this browser; no account required
- Compare up to three games
- Random game picker and details panel
- Responsive dark UI with animations
- Installable app shell with basic offline caching

## Catalog notes
The starter scores are editorial recommendations, not official Roblox metrics. Game details and availability can change. PLAYFINDER is an independent project and is not affiliated with Roblox Corporation.
